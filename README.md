Современное десктопное приложение для учёта личного бюджета с глубокими тёмными темами, встроенной финансовой аналитикой и локальным шифрованием данных.

---

## ✨ Основные возможности

* **📊 Учёт бюджета**: разделение доходов и расходов, создание кастомных категорий прямо из интерфейса и динамический расчёт финансовой нагрузки.
* **📈 Наглядная аналитика**: круговые диаграммы распределения расходов и столбчатые графики сравнения потоков на базе Matplotlib.
* **🛠 Встроенные инструменты**:
  * Онлайн-конвертер валют по актуальным официальным курсам **ЦБ РФ**.
  * Калькулятор инфляции и покупательной способности капитала.
  * Кредитный и депозитный калькулятор с расчётом переплат и капитализации.
* **🔒 Безопасность**: локальное шифрование базы транзакций алгоритмом AES (через библиотеку `cryptography.fernet`) с уникальным ключом устройства.
* **🎨 Кастомизация**: поддержка тем оформления (Dark, AMOLED, Dark Blue), регулировка масштаба интерфейса, шрифтов таблицы и переключение валют.

---

## 🚀 Запуск из исходного кода

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd F.13
   ```

2. Установите зависимости:
   ```bash
   pip install customtkinter matplotlib requests cryptography pillow
   ```

3. Запустите приложение:
   ```bash
   python budget.py
   ```
